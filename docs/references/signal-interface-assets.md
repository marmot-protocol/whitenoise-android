# Signal Forward arrow

By explicit user clarification on 2026-09-03, Forward uses Signal's broad
outlined right-turn arrow throughout the message action menu, selection
toolbar, and media viewer. The shared vector replaces the double-chevron
arrow while retaining each Material component's icon size, touch target,
tint, semantics, and forwarding behavior. Share uses its standard share icon.

- Commit: `879651dc47a7b18b67e7aea52a25197875024680`
- Local resource: `app/src/main/res/drawable/ic_forward.xml`
- SHA-256: `0e20b98eef8dfe9983a734e0b18b3de22dd0441e30fe8e6d2bf32a32278c4658`

The XML is unmodified, including automatic RTL mirroring. This is an artwork
import with no Signal runtime dependency. The already bundled Signal license
and notice remain at `app/src/main/assets/signal_emoji/LICENSE-Signal-Android.txt`
and `NOTICE-Signal-Android.txt` in that directory.

Rendering follows [Android's vector Icon guidance](https://developer.android.com/develop/ui/compose/graphics/images/material).
