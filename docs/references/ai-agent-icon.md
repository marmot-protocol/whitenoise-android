# AI agent icon

AI Agents in Settings and Talk to your agent in New Message share the Material
Symbols `auto_awesome` sparkle icon. Add Profile and contact actions retain their
person-plus icons.

- [Upstream SVG](https://github.com/google/material-design-icons/blob/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/symbols/web/auto_awesome/materialsymbolsoutlined/auto_awesome_24px.svg)
- Local resource: `app/src/main/res/drawable/ic_ai_agents.xml`
- Google Material Symbols, [Apache License 2.0](material-symbols-LICENSE.txt)

The SVG path is unchanged. Its Android vector wrapper uses the existing icon
size and theme tint, with no new runtime dependency.
