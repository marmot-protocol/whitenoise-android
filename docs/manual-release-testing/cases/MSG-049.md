[ ] **MSG-049 — Hold a message action to learn what it does** — Hold a message to open its action menu, then hold each item in turn, including Reply, Edit, Select, Copy, Translate, Read aloud, Forward, Keep on screen, Share, Save, Info, Report and Delete where they appear. Repeat with TalkBack using the Explain action, in light, dark and AMOLED themes, at the largest font size and in RTL. → **Expected:** Holding an item gives a haptic tick and opens a bottom sheet titled with the item's label and a plain-language description; the menu stays as it is, the action does not run, and nothing is replied to, forwarded, reported or deleted. Report and Delete state their consequences. A quick tap still runs the action. TalkBack lists Explain alongside the existing actions. Text wraps without clipping in every theme, font size and direction.
