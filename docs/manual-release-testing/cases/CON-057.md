1. [ ] **CON-057 — Follow an agent's work in a chat** — In a chat with an agent, ask it to read a file, edit it and run a command. Watch the chat, then open Agent activity from the chat header and expand the command and edit. Open the latest session controls, change an offered setting and start a new session. Open a subagent’s thread from its task in Agent activity. On a fresh visit where the loaded chat has no agent rows, open Agent activity from Chat details. Use Older and Newer in a chat with enough history to page. Make a step fail, then try a turn that fails. Repeat in a group, in light and AMOLED themes, RTL and large text. → **Expected:** Replies are ordinary messages. Running steps, their progress, session starts, plans and completed work stay out of the chat and leave no empty gaps. A failed turn appears in chat. The activity sheet opens at the latest activity, even while the chat shows older messages. Older and Newer page through the retained steps. The command shows its folder, exit status, duration and output, an edit opens its diff, and long output offers Show all. In a group each agent’s work is attributed to it. Subagent work and words stay in their thread. Replies from people remain visible in chat, as do waiting subagent requests. The most recent session lists its commands and offers the harness’s settings and actions. Closing the sheet returns to the same place in chat.
