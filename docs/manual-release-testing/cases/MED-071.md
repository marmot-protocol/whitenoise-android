1. [ ] **MED-071 — A failed multi-photo send stays compact in the composer** — Select two photos, turn on airplane mode and send them, so the send fails before the first photo.
    Then send a larger set of photos and documents that is split into several messages, and turn on airplane mode after the first message is sent.
    In each case look at the composer, type a reply in it, tap Details, then Hide details, turn airplane mode off and tap Retry.
    → **Expected:** The composer shows one line such as "2 of 2 not sent" with Retry and Details, and no progress bar, item list, explanation or Skip and Cancel buttons until Details is tapped; the composer stays usable for typing.
    Details shows the explanation, Skip failed, Cancel sending and each item, and Hide details collapses them.
    Retry sends each unsent photo once, without repeating the photos already sent, and the line disappears when the send finishes.
