1. [ ] **SET-049 — Remove attachments in one chat** — Use a chat holding attachments received over several months. In Settings → Data & storage → Manage storage, open that chat from Chats. Tap Remove older attachments, pick an age that leaves some newer attachments, read the confirmation and confirm. Then tap Remove all attachments, cancel once, tap it again and confirm. Go Back to the overview. → **Expected:** The chat's screen is titled with the chat's name and lists only its attachments, largest first, under Remove all attachments and Remove older attachments. Remove older attachments asks for an age, then confirms with the exact cutoff date, stating that attachments in this chat received before it are removed; only older attachments in this chat leave the list and other chats keep theirs. Remove all attachments confirms the chat's attachment count and that it frees up to the chat's size; Cancel keeps everything. Each finished removal shows "Removed N attachments · X freed" (or that nothing matched), and the chat's row on the overview shows its new count and size, or leaves when it has none.
