[ ] **NTF-036 — Long message in the expanded notification** — Receive a first message of exactly 119, 120 and 121 Unicode code points (the expanded-text threshold is counted in code points, so use plain letters for these and add one 120-code-point sample that contains an emoji), and one of about 200, 600 and 1,100 characters, in a DM and in a group, then expand each card in the shade at default and 200% font and compare collapsed and expanded states. Send a short second message behind a long first one, and a long message behind one or more carried messages. Repeat with previews off, with app lock on, in a muted chat and with an important-conversation Do Not Disturb exception. → **Expected:** A first message at or above the expanded-text threshold (currently 120 code points) expands through Android's standard expandable text and keeps Reply, Mark read, its sender and conversation settings. A shorter message, and any card that carries earlier messages, stays in the conversation template with every earlier message intact and as much of the newest text as Android shows. A message past 1,000 characters is cut at that bound. A single message that reaches the expandable text block is not a conversation card, so it does not get the important-conversation Do Not Disturb exception, and that is recorded rather than failed. Previews off shows only generic text and keeps the conversation classification and its Do Not Disturb exception. App lock shows only generic text and is not treated as a conversation. Neither reveals a sender, group or message text. Capture the shade at default and 200% font for the collapsed and the expanded state of each case and compare the visible text. The expanded card should show substantially more of a long first message, and of the newest message after carried history, than the collapsed one. Where it does not, truncation that Android applies counts as a platform limit only when the captures document the visible-text limit with the device, Android version, font scale and visible line counts, and that result is reported on issue #1901 rather than accepted silently.
