[ ] **FLD-008 — Folders beyond the loaded chats** — In a disposable account with more than 60 chats, make a folder whose rule matches chats spread across the whole list (for example Pinned, Group chats, a keyword, or an advanced filter mixing active and archived chats), plus one manually added chat and one excluded chat that the rule would match. Make sure several matches are older than the first 50 chats. Select the folder, scroll to its end, then use Select all and a bulk action such as Mute. Read its chip count, its count in Settings → Chat folders, and the folders listed in a matching chat's details. Change a chat so it joins or leaves the rule, edit the folder, switch accounts and back, and restart. Repeat with a folder that has a People rule. → **Expected:** The folder shows every matching chat, including the oldest ones, loading more as you scroll, plus the manual chat and never the excluded one. The chip's unread count, the Settings count and Select all all match the chats the folder shows, and the bulk action touches exactly those chats. Chat details list the folder for a matching chat even when it is far down the list. A chat that joins or leaves the rule updates the folder and its counts without duplicates. Editing the folder or switching accounts never shows the previous folder's or account's chats. A People folder still works as before over the loaded chats. While the app is still preparing chat names after a restart, a keyword folder shows its loaded matches rather than an empty folder, then fills in.
