[ ] **CON-038 — Opening a chat or inviting when storage is full** — On a disposable device with a populated account, fill storage until the app's database can no longer write (leave only a few megabytes free). Open a chat that is not already open, then try to create a new group and to invite someone to an existing group. Free space and tap Retry on the chat, then create the group again. → **Expected:** The chat shows "Not enough storage on this device. Free up space and try again." with a Retry control, never "Something went wrong" or a request to restart the app. Creating or inviting shows the same sentence instead of the generic failure, and names no recipient as the cause. After freeing space, Retry opens the chat and the group is created without restarting the app or switching accounts, and no other chat or account stays stuck.
