1. [ ] **CON-045 — Composer translate mode** — Install the Offline Translator engine. Open a chat, tap Plus → Translate, then pin Translate to the toolbar through Customize and toggle it from there. Type a sentence, pick a target language from the translation line, edit the text quickly, and send. Repeat with no engine installed, an attachment without caption, while replying, while editing a message, after locking/unlocking the app and after switching chats. Repeat in RTL, at 200% text and with TalkBack. → **Expected:** Turning translate on shows a second line above the typed line with the chosen language and the translation of the current text; it updates shortly after typing pauses. Send stays disabled while the translation is pending, failed or out of date, and when sent the chat receives only the translated text, never the original. The chosen language is remembered per chat. A missing engine shows a recovery message and blocks Send rather than sending the original. An attachment without caption sends normally. Editing a message turns translate mode off. Lock, chat or account changes drop the shown translation and no late result appears in another chat. The line, language picker and toggle remain readable and reachable at large text, in RTL and with TalkBack.
