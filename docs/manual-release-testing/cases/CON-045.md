1. [ ] **CON-045 — Composer translate mode** — Install the Offline Translator engine. Open a chat on a fresh install, tap Plus → Translate, decline the privacy notice, tap Translate again and accept it, then pin Translate to the toolbar through Customize and toggle it from there. Type a sentence, open the language picker from the translation line, type letters, accents and a language code into its search field, pick a target language, edit the text quickly, and send. Type back to an already translated sentence after a failure. Start dictation while translate mode is on. Repeat with no engine installed, a long message, an attachment without caption, while replying, while editing a message, after locking/unlocking the app and after switching chats. Repeat in RTL, at 200% text and with TalkBack. → **Expected:** The first Translate tap shows the privacy notice once; declining leaves translate mode off and accepting opens it, with no notice afterwards from either Plus, the pinned button or a message's Translate, which shares the same notice. Turning translate on shows a second line above the typed line labelled "Will send" with the chosen language and the translation of the current text; a long translation scrolls within a limited height and can be selected; it updates shortly after typing pauses. The "Will send" label appears only above an actual translation, never above the placeholder, progress or an error. Send is not shown while the translation is pending, failed, out of date or without a target language: a small progress ring holds its place while pending and nothing else shifts. Send appears once the translation is ready, and when sent the chat receives only the translated text, never the original. The chosen language is remembered per chat. The language picker is a black bottom sheet with a "Search languages" field that narrows the list on every keystroke ignoring case and accents, matches names and codes, shows an empty message when nothing matches, and opens with the current language checked and in view; dismissing it before any language exists turns translate mode off. A missing engine shows a recovery message and hides Send rather than sending the original. An attachment without caption sends normally. Typing back to translated text restores that translation without a new wait. Starting dictation turns translate mode off with a message, and Translate stays unavailable until dictation ends. Sending an attachment with a translated caption clears the typed caption. Editing a message turns translate mode off. Lock, chat or account changes drop the shown translation and no late result appears in another chat. TalkBack announces the toggle as selected while translate mode is on and reads the label with the translation. The line, language picker and toggle remain readable and reachable at large text, in RTL and with TalkBack.
