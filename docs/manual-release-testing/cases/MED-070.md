1. [ ] **MED-070 — Files tab Share keeps running when its row scrolls away** — In a chat with more files than fit on screen, open Shared Media → Files, open the menu of a large file that is not on the device yet and tap Share.
    While it is being prepared, scroll the list until that row is off screen, tap Load more if it is offered, then scroll back.
    Delete that file's message from another device while a second share of it is being prepared.
    → **Expected:** The row shows a progress indicator instead of its menu while the share is prepared, also after scrolling back, so it cannot be shared twice.
    The share sheet opens once the file is ready even though its row was scrolled away or more files loaded, and leaving Shared Media before then opens no share sheet.
    A file whose message was deleted while it was prepared opens no share sheet.
