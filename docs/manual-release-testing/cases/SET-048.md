1. [ ] **SET-048 — Largest attachments** — Use an account whose chats hold photos, videos, voice messages and files, including files sent with a name. In Settings → Data & storage → Manage storage, open Largest attachments. Read the rows, then tap several to select them, use Select all and then Clear selection, select two again and tap Remove. Cancel once, then Remove again and confirm. Repeat the selection once with TalkBack, and once in dark theme, RTL and large text. → **Expected:** Every chat's attachments are listed largest first. Each row shows its kind (Photo, Video, Audio or File) as the title, never the file name, with the chat and age below and the size at the end. A tap toggles selection and TalkBack announces the selected state. While anything is selected a pinned bar shows the live count and size ("2 selected · 14 MB") with Remove. The confirmation names the number of attachments and says it frees up to that size; Cancel keeps everything. After confirming, the removed rows leave the list, the selection clears and a message reads "Removed 2 attachments · X freed", and the overview figures drop when you go Back. Labels, sizes and the bar stay readable and unclipped in every theme, RTL and large text.
