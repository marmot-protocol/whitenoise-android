1. [ ] **CHL-042 — Reminder to save a new account’s private key** — On a disposable install, create an account with Sign up and open Chats before any conversation exists. Start one chat, then return to Chats. Tap Save key, go back, and tap Not now. Create a second account with Sign up, start a chat, and switch between the two accounts. On the second account, open Settings → Profile Keys and copy the private key, then return to Chats. Repeat the save with Export Encrypted Private Key and with Export Private Key on two more Sign up accounts. Sign in with an existing nsec, with Amber and with a remote signer, start a chat on each, and open Chats. Check the reminder in light, dark, AMOLED and at 200% text in RTL. → **Expected:** No reminder appears before the first conversation. After it, Chats shows “Save your private key” with “If you lose this phone, your key is the only way to keep this identity and your contacts.” above the list, with Save key and Not now. Save key opens Profile Keys for the active account, and Back returns to Chats with the reminder still shown. Not now hides it for that account only; the second account still shows its own reminder, and switching accounts always shows the active account’s state. After a copy, an encrypted export or a plain export, the reminder does not return, including after a restart. Accounts signed in with an nsec, Amber or a remote signer never show it, and neither do accounts created before this release. The reminder is outlined on pure black in AMOLED, and at 200% RTL both actions stay on screen.
