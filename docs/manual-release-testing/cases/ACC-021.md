1. [ ] **ACC-021 — Profile group lookups beyond the loaded chat list** — Use a disposable account with more than 200 chats. Far down its chat list, keep a named group shared with Bob, a group where Alice is an admin and Bob is not a member, and a group where Bob is a member but not an admin. Without scrolling the chat list, open Bob's profile and check Groups in Common, Add to a group and Make admin, then open Add to a group from the settings of Alice's direct chat with Bob. Add Bob to the far group and make him an admin of the other, then switch accounts while one of these pickers is still loading. → **Expected:** Each far-down group appears where it qualifies, exactly as a group near the top of the list would: Groups in Common lists the shared group and opens its conversation, Add to a group lists the admin group from both entry points, and Make admin lists the group where Bob is not yet an admin. A group whose roster is still being read shows the existing loading state, and one whose roster cannot be read shows the existing Retry, never an endless spinner. If the full chat list cannot be read, Groups in Common and both pickers show the existing Retry rather than a silently shorter list, and Retry recovers the missing groups. After adding or promoting, that group leaves the picker. The chat list keeps its scroll position and loaded chats. After the account switch no picker shows the previous account's groups.
