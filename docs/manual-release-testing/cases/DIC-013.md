1. [ ] **DIC-013 — Send after dictation keeps composer edits made while speaking** — In a disposable chat, start Dictate and, while speaking, paste text into the empty composer, then choose Send. Repeat after typing a few words before an existing draft, after clearing the draft, and after attaching one photo while speaking. In another run, leave the cursor mid-draft, add text after it while speaking, and finish with Send. → **Expected:** Each run sends exactly one message containing the edited composer text and the dictated words, with no "Not sent" warning, and the composer is empty afterwards. Dictated words land at the original cursor when it can still be located, otherwise after the edited text. The attached photo is sent with that text as its caption. Nothing is sent twice, and Retry or Paste afterwards adds no second copy.
