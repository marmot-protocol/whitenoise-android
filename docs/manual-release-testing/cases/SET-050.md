1. [ ] **SET-050 — Account-wide cleanup, re-download and list errors** — Use an account with attachments of different ages in several chats and some cached profile pictures. In Settings → Data & storage → Manage storage, tap Remove older attachments, pick an age, read the confirmation and confirm. Tap Clear pictures and temporary files and confirm. Open a chat whose attachments were removed and download one again. Back in Manage storage, force-stop the app, relaunch it and open Manage storage and Largest attachments as soon as Settings is reachable; if Chats or the list shows an error, wait for the account to finish opening and tap Try again (record N/A with the attempt if no error appears). → **Expected:** Remove older attachments asks for an age, then confirms with the exact cutoff date, stating that attachments received before it are removed in every chat; afterwards only older attachments are gone in every chat and the result message reads "Removed N attachments · X freed". Clear pictures and temporary files confirms that it frees up to the shown size and afterwards reports what was freed; profile and group pictures download again when next shown. Removed attachments still appear in their messages and can be downloaded again while the sender's copy is available. A list that cannot load shows its error ("Couldn't load chats" or "Couldn't load attachments") with a Try again row, and Try again resumes the list where it stopped without duplicating rows.
