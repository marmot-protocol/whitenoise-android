[ ] **ACC-024 — Open a linked-device account on a build without linked devices** — This needs a disposable test installation whose account A was linked to another device by a build with linked devices, plus an unlinked account B. Never use a personal installation. Install, in place and over that data, a build made from the same MarmotKit artifact that opens without linked devices, then launch it. If the app reaches the chat list with A signed out, switch to A from the account switcher. Then install the current build over it again and launch. → **Expected:** The build without linked devices never wipes, resets or signs out A. Startup, or switching to A, shows "This account uses linked devices, which this build can't open. Your data is kept. Install a build that supports linked devices over this one." A startup failure offers Copy but no Retry, and it does not loop. Reinstalling the linked-devices build in place opens A with its chats, history and linked devices intact, and B still opens. Ordinary release builds have no linked accounts, so this message cannot appear there.
