1. [ ] **MSG-010 — Forward one/many** — Forward a supported message to one chat and then multiple chats using search and direct selection. Next select an outside chat, filter to a folder, use Select all, deselect one member directly, then Select all and Deselect all before confirming. Repeat with a search query. → **Expected:** Origin and ineligible chats are excluded. Select all adds only the complete visible result; Deselect all removes only that result and preserves the outside choice. Bulk selection stays disabled while loading and is absent on All with an empty query. The compact header shows Close, the sending avatar to the left of the Forward title and a single-line count, with search at the right. The avatar is 48dp to tap, says Sending as NAME, and opens the existing account sheet only with multiple accounts. Search expands in the top bar and Back/Close clears it. Pinned/unpinned chats have their usual divider except during search. At least six rows fit on a normal portrait phone; the rounded Forward panel clears navigation/IME insets and the final row scrolls above it. AMOLED base surfaces remain black. progress names each target, every target receives one freshly sent payload, and no source encryption or author attribution leaks. Forward a text attachment from a source the device already holds (a received file opened earlier, and your own send) and from one it does not: the held source makes no new source download and the attachment still arrives once, a source whose retained copy is missing or unreadable still forwards by downloading it, a held source larger than the 32 MiB forward limit fails as too large without being downloaded again, and with local performance diagnostics enabled the forward's phases are recorded without any name, identifier or content. Send a text while offline or on a slow connection and, while it still shows Sending, forward it from its message menu and from a selection that also includes an older sent message; repeat with a selection that includes a photo that is still uploading. → **Expected:** A pending text forwards at once from its accepted text, without waiting for its own delivery, and each destination receives it once as a new message with no reply, sender attribution or temporary identity. The open picker keeps that text if the source then sends, fails or is cancelled, and none of those later changes rewrites, duplicates or cancels the accepted forward. A selection containing a pending send offers only Copy and Forward, and a still-uploading photo keeps Forward unavailable for the whole selection.
