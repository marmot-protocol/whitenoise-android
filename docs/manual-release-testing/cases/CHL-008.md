Compare the read-state command icons in the row menu, the selection bar, a read/unread swipe cue and the message notification's Mark as read action with previews shown and hidden, in Light/Dark/AMOLED, RTL and large text. Unread decoration/count appears, then clears after the conversation is read; the account switcher badge counts unread messages plus conversations that only need attention (a pending invitation counts once), and while MarmotKit is still preparing a summary the badge shows the last known count as provisional rather than zero.
