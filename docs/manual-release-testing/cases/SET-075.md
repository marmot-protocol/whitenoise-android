[ ] **SET-075 — Preview an emoji set as images, loading them only on request** — In Settings → Chats → Custom emoji → Emoji sets, open a discovered set that is not installed, one with an untitled hex identifier, an installed set at its current version and an installed set with an update available.
    Check light, dark and RTL at 200% text.
    In the not-installed set, tap Load emoji, scroll the grid, hold a tile and turn the network off before loading a second set.
    Retry a failed tile after the network returns. → **Expected:** Set rows and previews never show a hex identifier, coordinate or per-emoji host; an untitled set reads Untitled set.
    A remote preview shows the cover placeholder, the image host names and Load emoji, with no tiles or image requests before choosing Load emoji or Install set.
    After the tap, tiles pulse while loading, fill in as they scroll into view and show an error mark that retries on tap.
    Holding a tile shows its :shortcode:, and TalkBack reads it.
    The installed current version shows its grid at once from the device without Load emoji; an update-available set asks again before loading the new version.
    Install, Update, Check for update, Remove and Cancel behave as in SET-051.
