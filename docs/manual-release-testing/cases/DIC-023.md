1. [ ] **DIC-023 — Add emoji to the draft while dictating** — Pin Emoji and Camera to the composer toolbar and start dictation in a chat.
    While it listens, tap Emoji, pick an emoji, tap the keyboard button to return to the keyboard, and keep speaking.
    Then unpin Emoji so it moves to the Plus menu, start dictation again, open Plus, and pick an emoji from it.
    Finish each dictation with Paste.
    Then pin Plus, Emoji and Paste together and start dictation again.
    → **Expected:** Emoji opens the picker during dictation on either toolbar side and from Plus, and the picked emoji appears in the draft while dictation keeps listening.
    The picker offers no Browse sets or Settings button while dictation runs, and Camera, Dictate, Translate, Customize composer and the attachment rows of Plus stay unavailable.
    Each finished dictation keeps the emoji and adds the transcript to the same draft.
    With Emoji and Paste both pinned, Plus is disabled during dictation instead of opening an empty menu.
