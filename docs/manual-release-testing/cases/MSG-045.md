1. [ ] **MSG-045 — Send a sticker** — In a direct chat and a group, open Stickers from the composer toolbar or the attachment menu with at least one installed pack. Switch packs from the tabs, send a sticker, then start an edit and check the Stickers action, then send one with a draft in the composer. Reply to a received message with a sticker, and check it on the other device. Start a reply to your own photo while it is still uploading on a slow connection, and check the Stickers action before and after that photo is sent. Then reply to a text you sent while offline that still shows as sending. Send another sticker as a reply and pick a different message to reply to before it finishes sending. Repeat with large text, RTL and light/dark/AMOLED themes, offline, and after switching account or chat with the sheet open. → **Expected:** The sheet shows installed packs as compact tabs over a grid and states that images load from each pack's server. Tapping a sticker closes the sheet and sends exactly one sticker; it appears without a bubble at sticker size on both devices, and a draft stays in the composer. Stickers is offered while a reply is open, but not during an edit. While replying to your own photo that is still uploading, it stays hidden until the photo is sent. A text sent while offline already has its event ID, so Stickers stays available while replying to it, even while it shows as sending. A sticker sent as a reply shows the quoted message in a bubble above the sticker on both devices, and tapping the quote opens the original. The reply bar closes once the sticker is sent, but a reply picked while it was sending stays open. A failed send shows a sticker-specific error and sends nothing twice. A sticker reply never fails with that error because of its target: if the replied-to message still has no event ID when the sticker is sent, nothing is sent, the reply stays selected, and the notice says that message hasn't been sent yet, as for a text reply. The sheet never sends into a chat or account it was not opened from.
