[ ] **CON-052 — Follow an agent's work in a chat** — In a chat with an agent run by marmot-agents (Codex or Claude Code) on the current connector, send a prompt that makes it read a file, edit it and run a command. Watch the turn, tap its status line to show the steps, then open each step. Make one command fail. Repeat in a group with another person, in light and AMOLED themes, RTL and large text. → **Expected:** A Working line with Stop appears at the start of the turn and counts the steps as they arrive. Steps stay folded until you tap the line. Tapping again folds them. A long run of folded steps can leave a gap if the adjacent rows are short. Each step appears once and changes in place from a progress ring to done; updates never add rows. Opening a command shows the command without its shell wrapper, the folder, exit status, duration and output; an edit shows each file's diff; a plan shows its steps; output or a diff longer than 80 lines offers Show all. A failed command stays visible with its exit status in the error colour. The agent's replies are ordinary message bubbles. When the turn ends the line reads Worked for and the duration. In a group the agent is named once above its run of rows and its avatar closes the run. A session start is a centred line naming the model.
