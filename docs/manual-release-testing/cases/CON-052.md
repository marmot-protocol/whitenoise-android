1. [ ] **CON-052 — Follow an agent's work in a chat** — In a chat with an agent run by marmot-agents (Codex or Claude Code), send a prompt that makes it read a file, edit it and run a command. Watch the turn, then open each step. Repeat in a group with another person, in light and AMOLED themes, RTL and large text. → **Expected:** A Working line with Stop appears at the start of the turn. Each step appears once and changes in place from a progress ring to done; updates never add rows. Opening a command shows the command without its shell wrapper, the folder, exit status, duration and output; an edit shows each file's diff; a failed command shows its exit status in the error colour. The agent's replies are ordinary message bubbles. When the turn ends the Working line reads Worked for and the duration. In a group the agent is named once above its run of rows and its avatar closes the run; a new session shows a centred divider with the model.
