1. [ ] **GRP-002 — Edit name/description** — As admin edit name/description, cancel once, then save. Then erase the name and save, and rename A → B → A. On a compact screen in light and AMOLED, compare the empty and populated fields to Create Group. With the keyboard open, insert an emoji in the middle of the name, use Next and enter a long, multiline description. → **Expected:** Validation prevents invalid input; cancel preserves old values; save updates header/list/details on every member device. The separate editor uses the shared Settings header and the same pinned action area as Edit Profile. The button stays above the keyboard in a borderless footer. Preserve the exact name/description draft when canceling avatar selection or dismissing the keyboard. Both fields share Create Group's labels, alignment, spacing, focus rings and disabled treatment. Next focuses Description, the name stays single-line, and Description grows up to six lines before it scrolls. The emoji is inserted at the caret and Save stays reachable. After a successful rename, return to Chats without restarting: the row, its search and folder results, its archived entry and its sort position all read the new name straight away, and a rename that fails leaves the old one everywhere. Erase only a nonempty description and save: every member device shows no description, including after reopening details and after a later group-state update. Erase the name and save: every member device shows the group as unnamed, with its usual fallback title, and the description is unchanged. A rename leaves a description another admin set, even while the editor was open, intact. Chats shows the unnamed group under its fallback title at once, and searching the old name no longer finds it. Renaming back to an earlier name shows that name, not the intermediate one. Clear the description while the group is still syncing, for example right after reopening the app or reconnecting: the cleared description does not reappear when the sync finishes, and a description another admin sets afterwards still shows.
