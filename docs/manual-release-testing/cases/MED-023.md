[ ] **MED-023 — Local-first retained attachment access** — On disposable fixture accounts, retain a received file in native storage, evict only its Android presentation-cache entry, and hold three unrelated acquisitions open. Reopen and Save the retained file while offline, then exercise a local storage/preparation failure and repeat after account switch, removal and expiry. → **Expected:** The retained file returns exact bytes without waiting for a network slot or issuing a new acquisition; a local storage/preparation failure remains a failure and never silently redownloads. Account switch, removal and expiry never expose an old lease. Genuine outgoing retention is qualified separately under [MDK #2135](https://github.com/marmot-protocol/mdk/issues/2135); this received-file check does not establish outgoing durability. Repeat for a received photo and a received album with every photo automatic-download cell off and the network unavailable: while MDK retains the bytes the tile renders them, never shows or flashes a Download action, and opens on one tap with no request. Repeat after recreating the Activity (rotate the phone or change the font size) and after sending the app to the background and back, with a sent and a received photo, album and video: the same tiles stay shown with no Download, Retry or request, and a retained video opens on one tap each time. With TalkBack enabled, any initial local image-preparation spinner announces “Opening” with an “Open” action, never “Tap to download”; tapping it still opens the viewer once preparation finishes. Repeat with a populated received-photo/album fixture after memory eviction and a full process restart while offline. Compare first/last real image timings with the baseline, then resize a tile and test transparent PNG, GIF and animated WebP. For persistent display thumbnails, expect: A valid derivative renders without opening or transferring the original; a larger required size falls back to the existing original path. Derivatives never grant original availability to Open, Save or Share. Corrupt derivatives with automatic downloads disabled do not start transfers. Clear Cache, attachment/chat/account removal and expiry remove every cached size across restart, including when cleanup races an encode or read; switching accounts cannot publish late pixels. Manage Storage includes the encrypted derivatives, whose total remains at most 32 MiB.
