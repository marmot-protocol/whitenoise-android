[ ] **FIND-011 — In-chat search while full history loads** — In a large disposable group with history older than the loaded window, open in-chat search and type a word that matches both a visible message and several older ones; press the up/down arrows repeatedly before the count appears, then again once it does. If a local scan failure occurs, inspect the status text and use the retry control. Scroll up to an older message, open in-chat search, step to a match far older than that position, then close search with the toolbar close button. Repeat, closing with system Back instead, then press Back once more. Check light/dark, RTL and 200% text. → **Expected:** While older history is still being searched the bar reads Searching all messages… with no partial count and both arrows disabled; once the scan finishes the final count appears and each press moves to one distinct matching message, centred and highlighted, keeping the selected match when the set grows. A failed scan never shows the loaded matches as the whole result: it labels the count as in loaded messages, or says older messages could not be searched, and the retry control restarts the full search. Closing search, with the toolbar button or with Back, returns the transcript to the message you were reading when search opened, once, even while older history is still paging back in. Dragging the transcript during that return leaves it where you dragged it. Back after search has closed leaves the chat as usual.
