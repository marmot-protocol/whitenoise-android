1. [ ] **SET-061 — Link a new device** — This needs the build on two devices or emulators and a disposable local-key account. Sign in to the same account on both. On the new device open Settings, Account, Linked devices and choose Link this device. On the device already signed in, wait for the request, compare the emoji and choose Link device; on the new device choose They match. Repeat, each time from a new device that is signed in but not yet linked (remove it from Linked devices on the approving device, then remove the account from it and sign in again), and each time do one of: choose Not now on the approving device; choose Cancel on the new device; let the request time out; tap an action twice quickly; close the request with Back; press Back on the new device's step and reopen it from Linked devices; send the approving app to the background before the request arrives and bring it back after it timed out; open Options, rename the device and turn a choice off before Link device; open Options and enter a device name longer than 64 bytes. Repeat with a second profile active on the approving device, and with an account that signs through an external signer app. Repeat in dark, AMOLED, RTL and at the largest font size, with TalkBack, and with notification permission denied. → **Expected:** The new device says to open White Noise on another device and keep both apps open, then shows seven emoji four over three, each with its name under it as on the other apps, with They match and Cancel; at the largest font size a name shrinks to fit on one line and never breaks inside a word. The approving device shows the same seven emoji in the same order with Link device, Not now and an Options row; the Device name field, empty, and Add to all my chats and Bring chat history, both on, appear only after Options is opened. Linking without opening Options leaves both choices on; the new device appears in both rosters under the default name sent by the approving device, while a name typed under Options is kept, and choices changed under Options are the ones applied. TalkBack reads each emoji with its position, for example "1 of 7". After both confirm, the new device says it is linking and only says This device is linked once linking has finished; the approving device says it is waiting for the new device and then that the new device is linked. Both devices then list each other under Linked devices. An action that fails says so on the step itself. Not now, Cancel, a timeout and a mismatch each end with their own message and link nothing; Try again starts a fresh attempt. A second quick tap submits nothing extra. Back closes the step or the request without cancelling or declining it, and Linked devices offers the way back in while linking is in progress. A request that expired in the background is shown as ended, never as a fresh request, and no notification is posted for a link request. A too-long name says so, keeps the options open and disables Link device. If another device finishes the request, Done or Close still works. Closing the checking step before the emoji arrive allows that same request to present its comparison. With another profile active, a notice names the profile that received the request; Review switches to it and shows Checking the new device… with only Not now until that profile has read the request again, then the comparison, and Not now only hides the notice. A settled request stops offering Review for another profile. An external-signer account is told linking isn't available yet and is offered no link action. Nothing is clipped at the largest font size or in RTL. After Link device, the approving device says it approved the device and that joining usually takes under a minute, until it says the new device is linked. On the new device, an empty chat list says This device is linked for the first minutes after linking, explaining that existing chats are added by the other devices and that a new one can be started, instead of No Chats. A chat another of the account's devices added this one to can arrive as an invitation; it never names the account itself as the inviter, it is never accepted without a tap, and Accept opens it as an ordinary chat. Turn off Bring chat history, lock and unlock the approving phone, then inspect Options before approving. The same request keeps the choice off and a different request starts with fresh choices. On the requesting device switch profiles while waiting. A locally started request cancels before this device submits They match. Switch after submitting They match and the confirmed link continues. A plain switch shows no link error. Leaving the screen with Back alone keeps the request available. With chat joins outstanding, use double text size and a short split-screen window. Scroll to New Chat and verify it opens the new-chat flow.
