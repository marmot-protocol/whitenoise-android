[ ] **TTS-003 — Unknown-engine trust warning** — On a device with only an unacknowledged external engine, try Speak aloud from a message, from a text attachment, and with auto-read enabled when opening or returning to a chat with unread messages. Dismiss the warning, then retry and choose Speak anyway. Repeat with a saved unacknowledged engine selection. Try a documented local default with no saved approval. While a warning is open, leave the app or change ownership before trying to approve it. In Settings, select a different unknown engine, cancel, then reselect and proceed. Reselect it again and try a second unknown engine. → **Expected:** Dismissal and a stale approval play nothing. Proceed starts eligible speech. For an unverified connection, approval covers only that connection, even if Settings already recorded approval for its package. Replacing that connection prompts again. This also applies to a documented local default because Android’s public API cannot identify the connected speech service. In Settings, Cancel keeps the previous engine, Proceed selects and remembers the accepted engine, and an unacknowledged engine still warns. During backlog preparation, switching profiles (including away and back) or disabling auto-read leaves the old backlog silent.
