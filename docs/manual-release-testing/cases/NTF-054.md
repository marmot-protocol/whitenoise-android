1. [ ] **NTF-054 — Starter notification profiles** — On a fresh install with the device in English, open Settings → Notifications → Notification profiles and look at the list and the chat list. Open each starter profile, then delete all three, force-stop and reopen the list. Repeat the fresh install with the device in German. → **Expected:** The list shows Sleep, Work and Focus, each reading "No schedule", and nothing is held back; the Notifications row reads Off and the chat list has no profile button. Sleep has Notify for mentions off and, when Turn on automatically is switched on, shows 22:00 to 07:00 every day; Work has mentions on and shows 09:00 to 17:00 on weekdays; Focus has mentions on and no schedule. Each can be edited, turned on from the editor's schedule or the quick sheet, and deleted like any other profile. After deleting all three and reopening, the empty state shows and the starter profiles do not return. Saving or turning on a profile does not add the chat-list profile button. In German the starter profiles are named Schlafen, Arbeit and Fokus.
