1. [ ] **CON-047 — Keyboard-to-emoji swap keeps the composer expanded** — Open a chat with an empty composer, tap the editor so the keyboard opens, then tap the emoji button. Switch back to the keyboard, then to emoji again. Repeat with a reply open, in RTL, at the largest font size and in light and dark themes. → **Expected:** The composer keeps its expanded editing layout while the emoji pane replaces the keyboard and while the keyboard returns; it never folds to the one-line resting row. The pane rises and lowers with the composer in one smooth motion without a flicker, jump or blank frame. Closing the emoji pane with Back returns an empty composer to its resting row when no reply is open; with a reply open the composer keeps its expanded layout.
