Link device B with Bring chat history on, and separately link device C with it off. Before opening anything on B, note how each chat is listed. On B open the chat while history is arriving, scroll up and down, and have a peer send new messages at the same time. Turn B's network off mid-transfer and back on, and force-stop and reopen B. Rename device A while B shows imported history. Repeat in RTL and at the largest font size, with TalkBack. → **Expected:** Chats the account already accepted are listed on B as accepted, without the invitation badge and without Accept or Decline inside, in the same order as on A and with their real last-message times; record it as a defect if they stay invitations for more than a minute, and do not accept them by hand. Messages the account sent show as its own and never as pending or failed. The list does not jump while history arrives: the message being read stays in place and new messages still arrive at the bottom. No notification, sound or vibration is posted for imported messages. After a restart the same state is shown. On C, linked with Bring chat history off, the chat shows only messages from after it joined, with no import line and no receiving notice.
