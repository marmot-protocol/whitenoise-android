[ ] **SET-071 — History backups: restore history on a second install** — On install A, turn on history backups, send messages in a group with install B's account, then keep A charging on Wi-Fi until a backup has run. On a fresh install of the same account that has rejoined that group, open Settings → Account → History backups, type invalid words and tap Restore history; then enter A's twelve words. Start a second restore while the first runs, cancel one restore, then restore again to completion. Leave the screen during a restore and return. → **Expected:** Invalid words show the invalid-words error and nothing starts. Valid words show Looking for backups, then the restored message count, and finish with Restore finished (or the partial message if some backups could not be read). Restored messages appear only in chats this install is still in; no chat is rejoined and the account keys are unchanged. Cancel stops the restore and keeps messages already restored. Leaving the screen does not cancel the restore, and returning shows its current progress. The typed words are cleared from the field when a restore starts and never appear after leaving the screen.
