[ ] **SET-071 — History backups: restore history on a second install** — On install A, turn on history backups, send messages in a group with install B's account, then keep A charging on unmetered Wi-Fi and allow the daily backup pass to run. Use a fresh fixture account for this test so an existing daily schedule does not delay the first write. The writer label confirms setup only. For a controlled fixture, verify that its relay accepted a backup pointer listing an archive before starting the restore. If only the UI is available, use a positive restored-message count for the prepared chat as evidence of publication and restore, and record a zero result as unverified. On a fresh install of the same account that has rejoined that group, open Settings → Data & storage → History backups, type fewer than twelve words, then submit twelve words with invalid spelling; then enter A's twelve words. Start a second restore while the first runs, cancel one restore, then restore again to completion. Leave the screen during a restore and return. Then have install B invite this install to a group whose history install A had backed up before this install joined, open that chat's Chat Info, enter A's words again and reopen Chat Info. → **Expected:** Incomplete entries keep Restore history disabled. Invalid words show the error at the input, leave all twelve words editable, and start no restore. Valid words show Looking for backups, then the restored message count, and finish with Restore finished (or the partial message if some backups could not be read). Restored messages appear only in chats this install is still in; no chat is rejoined and the account keys are unchanged. Cancel stops the restore and keeps messages already restored. Leaving the screen does not cancel the restore, and returning shows its current progress. Chat Info for the newly joined group shows a notice that a backup has older messages and names Settings → Data & storage → History backups; other chats show no notice. The typed words are cleared from the field when a restore starts and never appear after leaving the screen.
