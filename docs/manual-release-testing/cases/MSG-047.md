1. [ ] **MSG-047 — Receive a sticker** — Receive stickers from an installed pack and from a pack that is not installed, with image auto-download on and then off. Receive one with a caption or reply and one whose image fails to load. Remove an installed pack while offline, then receive a sticker from it. Check the chat list preview and a notification for each, and listen with TalkBack. → **Expected:** A sticker from an installed pack loads by itself only while image auto-download is on; otherwise it shows a tap-to-load placeholder and contacts no server before the tap. A sticker from a just-removed pack waits for a tap even when refreshing the pack list failed. A failed image shows a retry state and doesn't reload while scrolling until tapped. A sticker with a caption, reply or media keeps its bubble and text. Previews and notifications read "Sticker" unless a caption takes precedence, and TalkBack reads the alt text, then the emoji, then "Sticker".
