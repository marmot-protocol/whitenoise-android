[ ] **RDR-006 — Code paths and horizontal reading** — Send and receive fenced and indented code containing leading-slash and nested paths, Unicode filenames, explicit newlines and an oversized filename. Repeat in narrow Light, Dark and AMOLED bubbles, with RTL surroundings and system/app large text. Pan to the source ending, then long-press its final word; open the full-screen reader and repeat. Open the same Markdown as a text attachment and a controlled referenced event, including a path whose slash crosses the reader's 4096-character item budget. In bubbles, full-screen messages and attachments, copy the whole source and a selected filename; check read-aloud highlighting/seek geometry after horizontal movement and ordinary vertical reader scrolling. In referenced events, check the existing link/reference Copy actions; selected-source Copy is not currently available there. Keep plain prose, inline code and a math block as controls. → **Expected:** Source code keeps authored line boundaries and LTR punctuation inside a bounded horizontal viewport; a slash never detaches from its following filename through soft wrapping or an artificial item boundary. Every source ending remains reachable without widening the screen. Where native source selection is available, it targets the visible word, and source copying retains original text after existing sanitization, without inserted spaces or joiners. Referenced-event chunks reconstruct the original source, and link/reference Copy retains its existing behavior. Speech geometry follows the scrolled source. Plain prose and inline code retain soft wrapping; math retains its source/newline treatment. Leaving selection preserves the code viewport, while opening different source resets its presentation. Preserve all accounts/history and restore changed settings.
