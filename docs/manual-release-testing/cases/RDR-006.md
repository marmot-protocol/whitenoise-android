[ ] **RDR-006 — Code paths and horizontal reading** — Send and receive fenced and indented code containing leading-slash and nested paths, Unicode filenames, explicit newlines and an oversized filename. Repeat in narrow Light, Dark and AMOLED bubbles, with RTL surroundings and system/app large text. Pan to the source ending, then long-press its final word; open the full-screen reader and repeat. Open the same Markdown as a text attachment and a controlled referenced event, including a path whose slash crosses the reader's 4096-character item budget. Copy the whole source and a selected filename; check read-aloud highlighting/seek geometry after horizontal movement and ordinary vertical reader scrolling. Keep plain prose, inline code and a math block as controls. → **Expected:** Source code keeps authored line boundaries and LTR punctuation inside a bounded horizontal viewport; a slash never detaches from its following filename through soft wrapping or an artificial item boundary. Every source ending remains reachable without widening the screen. Native selection targets the visible word, and copying retains original source text after existing sanitization, without inserted spaces or joiners. Speech geometry follows the scrolled source. Plain prose and inline code retain soft wrapping; math retains its source/newline treatment. Leaving selection preserves the code viewport, while opening different source resets its presentation. Preserve all accounts/history and restore changed settings.
