Leave each banner untouched, then, before it ends, send a second message to the same chat, let the invite sender's display name resolve, and let a late text correction arrive. Repeat after swiping a card away before its second message arrives, with the conversation muted, with another account active and with app lock on. → **Expected:** The banner stays for the system's normal heads-up time and is not withdrawn by a same-chat update, a name or avatar refresh, a corrected message or an invite identity refresh. Android's own throttling, cooldown, Do Not Disturb and accessibility timeout still decide the banner's length, so record the device, Android version and settings rather than treating a platform-shortened banner as a failure.
