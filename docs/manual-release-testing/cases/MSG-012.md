1. [ ] **MSG-012 — Multi-message selection** — Enter Select, choose mixed incoming/outgoing messages, scroll, deselect, and apply each enabled batch action. Include a received attachment the device has not downloaded: start its download, then select the message while the transfer is still running; in a second run, let the download finish before selecting it. → **Expected:** Selection/count survives scrolling, invalid destructive actions are disabled, and only selected messages are affected.
