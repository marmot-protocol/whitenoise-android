1. [ ] **CHL-034 — Select all beyond loaded chats** — With an account holding at least 120 active chats and 60 archived chats, open Chats without scrolling, long-press a row and tap Select all. Repeat in the Archived system folder, then with search open, Unread only and a custom folder. Mark all read, mute, archive and unarchive from these selections. → **Expected:** In unfiltered Chats and the untouched Archived folder the selection count equals every chat in that view, not only loaded rows, and stays the same while scrolling. Actions stay disabled until the count settles; tapping a row before then keeps that row choice. Loaded left groups stay selected. Delete, Leave, folder add/remove and manual pin order are absent while unloaded chats are selected; both read and both mute directions remain. Each action reaches every chat still in the view; a chat that left meanwhile is skipped. Search, Unread only and custom folders still select only their loaded rows. If the complete read fails, only loaded chats stay selected and a short notice says so. Switching account or folder during the read leaves no stale selection.
