1. [ ] **SET-047 — Manage storage overview and Keep media** — Use an account with several chats holding attachments. Open Settings → Data & storage and tap Manage storage at the top, then read the usage panel with and without TalkBack. Change Keep media from a longer window to a shorter one and confirm, then to a longer window. With Manage storage open, switch to another account. Search Settings for "storage", "largest attachments", "keep media" and "clear temporary files", and for the name of one of your chats. Repeat the overview and the Keep media confirmation in dark theme, RTL and large text. → **Expected:** The Data & storage row reads "Manage storage" with "See what's stored on this device and free up space" and opens the screen; Back returns to Data & storage. The panel shows the total, a bar, and a legend naming Attachments (with its count), Messages and chat data, Profile and group pictures and Temporary files ("Shared by all profiles on this device") with sizes, plus Unused database space only when there is some. It pulses under "Calculating…" until figures arrive, and TalkBack reads it as one "Storage used: …" sentence. A shorter Keep media window asks first, naming the window, and removes older attachments; a longer one applies at once with "Keep media setting saved". After the account switch no figure, chat or selection from the first account remains. The four searches find Manage storage, Largest attachments, Keep media and Clear pictures and temporary files; chat names and attachments never appear in Settings search. Dark theme, RTL and large text keep every label, size and button readable, unclipped and correctly ordered.
