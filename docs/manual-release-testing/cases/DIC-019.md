1. [ ] **DIC-019 — Continue while dictation transcribes** — With caller-audio dictation and a slow recognition result, dictate a distinctive first phrase and tap Paste. Tap the mic beside Cancel, speak a second phrase and tap Paste before the first result returns. Repeat after Send, then repeat with Cancel and with backgrounding during the second recording. → **Expected:** The mic starts the second recording while the first transcribes. The listening pulse has a thin progress ring and the controls show icons only. The first result lands before the second, which uses the cursor position after the first lands. Cancel discards only the second recording. Backgrounding ends the second capture and keeps its recorded audio for transcription.
